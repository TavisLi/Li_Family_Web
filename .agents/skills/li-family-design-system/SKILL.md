# Li Family visual language

Read [the canonical product visual contract](../../../docs/design/li-family-visual-system.md) for the affected presentation family and shared rules. Inspect the actual component and tokens before changing them. The contract distinguishes current implementation from rules for new work; it does not authorize a site-wide rewrite.

For a new page, choose Standard, Premium, or explicitly requested Showcase effort; then choose the lowest motion tier that communicates state or story. Reuse the current typography, tokens, button and navigation patterns when they fit. Let Editorial, Cinematic, Scrapbook, and ordinary portal pages vary within the shared family identity. Do not apply one presentation's effects to another by default.

For a small fix, read only the relevant contract section. After a visual change, use `visual-qa` for the affected surfaces and viewports. Follow `AGENTS.md` for access, scope, and delivery authority.
