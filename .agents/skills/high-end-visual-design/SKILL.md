# Showcase visual specialist

Use only when the user explicitly requests a Showcase surface, cinematic hero, special presentation, visual experiment, or equivalent named deliverable. The [Li Family visual system](../../../docs/design/li-family-visual-system.md) defines shared identity and motion limits. First define the specific story or hierarchy the stronger treatment serves. Use only the techniques that support it and keep navigation, readability, performance, and reduced motion intact.

This Skill is supporting technique, not another Creative Director. `design-taste-frontend` owns the single design read. Existing repository fonts, Tailwind, shadcn, Lucide, and assets remain in place unless separately authorized. Do not apply showcase effects to ordinary portal UI or infer permission to redesign other pages. Validate with `visual-qa` and follow `AGENTS.md` for authority.

For a relevant task, search and read only the applicable headings in [the preserved technique reference](references/showcase-techniques.md). The reference is not a checklist that must be applied in full.
