# Triage labels

The engineering skills use the following canonical role-to-label mapping. Apply the mapped GitHub label rather than creating a synonym.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill refers to a canonical role, use the label in the middle column. Update only that column if the repository adopts different GitHub label names.
