# Web Li Agent Operating Contract

## 自主與查證
理解 task、核對 Git status／HEAD／既有變更、定位 seam。已批准可逆工作自主完成、簡述假設；只詢問影響 scope、產品、架構、privacy、acceptance 的實質歧義。不重做 intake／批准；受阻仍繼續獨立安全工作。

自主選 context、方法與驗證；契約不明、變更或衝突時查 owner，不預讀清單。docs/agent-context-routing.md 是可選索引。Skills 按任務／使用者指定啟用，不因 UI 小修觸發 redesign／產圖，不擴權或覆寫 stack。

## 權限與保全
遵守平台 system／developer。Repository precedence：目前使用者 task／有效批准 → CONTEXT 穩定詞彙 → accepted ADR → 架構契約 → AGENTS → owning domain／Phase rules → task-scoped Skills → historical evidence。Proposed ADR 非決策，限定例外不泛化；契約與 schema／ADR 衝突時回報，停受影響高風險動作，不靜默覆寫。

獨立授權：GitHub Issue／PRD 發布或修改、本地修改、Preview deployment、Production read-only、Production migration、Production content／media writes、destructive operations、merge／release、closeout。Migration、baseline metadata、content、media、relationship cutover、destructive cleanup 分別報告／批准。Phase 完成、工具／Skill、歷史成功、可 rollback 不擴權。

批准重用須 target、allowed/excluded actions、scope、baseline、環境、stop conditions、有效期間／Phase 相符且未撤回；有效不重問，失效／證據不足停受影響操作，不擴權。外部／高風險動作前查 Playbook 對應 gate；文件準備不觸發 apply／live access。

Scope 外既有 dirty／untracked files／assets 不修改、還原、清理、stage、commit，除非使用者明確納入。只改任務所需。既有分支核對、不擅切；新分支用最新已確認 main 的 codex/phase-* 或 codex/docs-*；不直推 main，提交／發布依 authority，audit 可固定 HEAD。

## 安全底線
Public／Family access 必須由 collection／data layer 強制，不能只在 UI 隱藏。Secret 不進 client、log、report、fixture、HTML、Git 或 Issue／PR。Payload 是 runtime published truth，content-source 是 seed input；共編採 Base／Source／Current safe mode：Source-only 可更新、Current-only 保留、雙改不同值 conflict、Missing Base 既有 record preserve-current。Travel-only 不以全量 seed 順帶改 Users／member media／Home Config。

持久化需求才改 Collection；核對 Collection／types／migration history，預設 additive、nullable、backward-compatible。Schema 變更依 Playbook §9：generate types → generated migration → SQL／up／down 人工審查（適用時）→ disposable/local rehearsal → approval → apply／read-back。Production mutation 須 dry-run、before/after 計畫、rollback、獨立批准與 read-back；inventory 先有 read authority。Cleanup 另列 scope，不借舊 waiver。

Data-loss／dev-schema warning、資料破壞風險、inventory／deployment／驗證 commit 漂移、未批准 collection／delete／update、reconciliation conflict、read-back timeout／failure、UNKNOWN、私密 response／metadata／JSON-LD 洩漏：保留證據、停受影響操作；不放行 warning、不自行 retry／repair mutation、不將 UNKNOWN 當成功或失敗。

## 既有實作與驗證
沿用現有架構／stack；data access 經 src/lib/data，projection 派生 generated types，不用 any／第二份 schema。API 不確定時查 repository 實際安裝版本官方文件。UI 沿用 Tailwind／shadcn；禁 React inline style={{}}（框架輸出例外）；保留合適 loading/error boundary；缺圖用 ImageFallback，非內容完成證據；media relation 預設 optional，required 需需求／migration 證據；用 R2 S3 adapter，禁 Vercel Blob。

按風險／acceptance 充分驗證；不預讀 Playbook §10–§11，有疑問查 owner，不豁免適用要求。檢查 diff／secret；適用 build 完成才 tsc，不並行、不臨時裝 Prettier。文件-only 說明 runtime QA 不適用；executable config/schema/runtime 影響須重判。HTTP／HTML／focused tests 可作 Browser unavailable fallback，明列 Browser／Preview 缺口；acceptance 未滿足保留 blocker。Build／READY／HTTP 200 非 runtime／data／release 完成證據。

報告實際變更、驗證與缺口；PR／Phase closeout 查 Playbook §11–§14／模板，acceptance 全完成才 Closes。歷史用 addendum 補狀態，不改寫 memory；有效 preparation 是規格非證據。#105 擁有 runner／manifest／ledger／receipt／bounded I/O／approval invalidation／Preview QA execution contract，不複製或假定已完成。
